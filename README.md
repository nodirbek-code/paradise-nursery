# Paradise Nursery Shopping Application

A React-based e-commerce single-page application built with Vite and Redux Toolkit for browsing and purchasing house plants.

## Features
- Responsive landing page with a background image and "Get Started" button.
- Plant catalog organized by categories (3 categories, 6 plants each).
- Redux Toolkit integration for global shopping cart state management (`addItem`, `removeItem`, `updateQuantity`).
- Interactive cart summary with total calculations and checkout simulation.

## Run locally
```bash
npm install
npm run dev
```
